## Step 1 — Install Python dependencies

```bash
pip install flask flask-cors requests opencv-python dlib imutils librosa scikit-learn joblib scipy
```

FFmpeg is also required for audio extraction:
- Windows: https://ffmpeg.org/download.html (add to PATH)
- Mac: brew install ffmpeg
- Linux: sudo apt install ffmpeg

---

## Step 2 — Get required model files

**dlib landmark file** (download once, ~99MB):
```
http://dlib.net/files/shape_predictor_68_face_landmarks.dat.bz2
```
Extract and place `shape_predictor_68_face_landmarks.dat` in the project root.

**Audio model** — must be trained first. Run on Kaggle or locally:
```bash
python Audio_Analysis.py --train
```
This generates `models/audio_model.pkl` and `models/audio_model_meta.json`.

---

## Step 3 — Test the backend locally

```bash
python backend.py --test
```

This runs both models against:
- `data/testing/fake/heygen_amber_test3.mp4`
- `data/testing/real/test_real_3.mp4`

To test your own video, edit this line at the top of `backend.py`:
```python
TEST_VIDEO_PATH = "path/to/your/video.mp4"
```

---

## Step 4 — Start the backend server

```bash
python backend.py
```

Server runs at: http://localhost:5000
- Health check: GET  http://localhost:5000/health
- Analyse URL:  POST http://localhost:5000/analyse_url
- Analyse file: POST http://localhost:5000/analyse_file

The backend must be running for the Chrome extension to work.

---

## Step 5 — Load the Chrome extension

1. Open Chrome and go to: chrome://extensions/
2. Enable "Developer mode" (top right toggle)
3. Click "Load unpacked"
4. Select the `extension/` folder
5. The DeepGuard icon will appear in your toolbar

**Icons** — you need to add icon files at:
```
extension/icons/icon16.png
extension/icons/icon48.png
extension/icons/icon128.png
```
Any square PNG images will work for now during development.

---

## Step 6 — Using the extension

1. Start the backend: `python backend.py`
2. Navigate to a video on YouTube, TikTok, Instagram, X or Facebook
3. Click the DeepGuard icon in the toolbar
4. Click "Analyse This Video"
5. Wait for results (typically 10-30 seconds)

## API Reference

### POST /analyse_url
```json
Request:  { "video_url": "https://example.com/video.mp4" }
Response: {
  "verdict":    "REAL" | "FAKE" | "SUSPICIOUS" | "INCONCLUSIVE",
  "confidence": 0.0-1.0,
  "reason":     "Human readable explanation",
  "ear": {
    "verdict":      "...",
    "blink_rate":   14.2,
    "blink_count":  4,
    "desync_ratio": 0.02,
    "duration":     16.5,
    "reason":       "..."
  },
  "audio": {
    "verdict":           "...",
    "fake_probability":  0.82,
    "real_probability":  0.18,
    "reason":            "..."
  }
}
```

### POST /analyse_file (local testing only)
```json
Request:  { "video_path": "data/testing/fake/heygen_amber_test3.mp4" }
Response: same as /analyse_url
```

## Troubleshooting

| Problem | Solution |
|---|---|
| `Backend offline` in extension | Run `python backend.py` in terminal |
| `Model not found` error | Run `python Audio_Analysis.py --train` first |
| `dlib landmark model not found` | Download `.dat` file (see Step 2) |
| `No video detected` on page | Navigate to a page with an actual video playing |
| FFmpeg errors | Install FFmpeg and ensure it's in PATH |
| Extension not seeing video | Some platforms use blob URLs — content.js may need updating for that platform |
